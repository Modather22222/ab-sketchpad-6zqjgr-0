# SketchPad

Freehand sketching demo app built with Flutter and Material 3. Draw on a touch
canvas with brush/eraser tools, pick colors and stroke sizes, undo/redo, clear
the canvas, and export the result as a PNG. Sketches are saved to a local
gallery (JSON in the system temp directory) so they can be reopened or deleted
later.

Run with `flutter pub get && flutter run`; test with `flutter test`.
